# Sortir.com

## Présentation du projet

**Sortir.com** est une application web développée en PHP dans le cadre de ma formation à l’ENI École Informatique.

L’objectif du projet est de proposer une plateforme permettant aux utilisateurs d’organiser et de gérer des sorties. Le développement s’appuie sur un document de vision, des spécifications fonctionnelles, des diagrammes de conception et un modèle de base de données fournis au démarrage du projet.

Le projet est organisé en plusieurs itérations, chacune visant à fournir une version fonctionnelle de l’application.

## Fonctionnalités

Les fonctionnalités sont développées progressivement selon les priorités définies dans le cahier des charges.

Les fonctionnalités réalisées lors de l’itération 1 constituent le périmètre principal du projet.

Les fonctionnalités supplémentaires dépendent de l’avancement du développement.

## Technologies utilisées

- **Langage :** PHP
- **Base de données :** SQL Serveur
- **Frontend :** HTML, CSS et JavaScript, selon les technologies utilisées
- **Outils de développement :** PHPStorm

## Conception

Le développement s’appuie sur plusieurs documents de conception :

- Document de vision du projet
- Processus de gestion des sorties
- Description des fonctionnalités par itération
- Diagramme d’état du cycle de vie d’une sortie
- Diagramme de classes du domaine
- Script de création de la base de données

## Installation

1. Cloner le dépôt Git :

   ```bash
   git clone <URL_DU_DEPOT>
   ```

2. Placer le projet dans le répertoire adapté à votre environnement PHP.

3. Créer la base de données à partir du script SQL fourni dans le projet.

4. Configurer les paramètres de connexion à la base de données.

5. Démarrer l’application selon la configuration de votre environnement local.

## Suivi du projet

Le suivi du développement repose sur une liste de tâches permettant d’identifier les fonctionnalités réalisées et celles restant à développer.

Le projet est évalué à travers :

- Une démonstration de l’application
- Une revue de code portant sur une fonctionnalité
- Un bilan des fonctionnalités développées et des améliorations restantes
- Un retour d’expérience sur les compétences acquises pendant la réalisation du projet

## Contexte

Projet réalisé dans le cadre de la formation en développement informatique à l’ENI École Informatique.
